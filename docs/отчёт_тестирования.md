## 5. Ограничения

- Разметки (ground truth) для этого набора нет, поэтому precision/recall по нему не считается. Метрики качества обучения — в `ml/runs/detect/ml_v2/` (`results.csv`, матрицы ошибок).
- Освещённость и сезон определяются по статистике изображения (яркость канала V, доля зелёных и малонасыщенных пикселей), а не по метаданным.
